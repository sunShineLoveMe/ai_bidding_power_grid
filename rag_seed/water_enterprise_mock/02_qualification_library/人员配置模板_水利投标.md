# 水利项目人员配置模板

## 施工类项目人员配置

| 岗位 | 资格要求 | 主要职责 |
| --- | --- | --- |
| 项目经理 | 水利水电工程专业注册建造师、安全生产考核合格证 | 全面负责项目进度、质量、安全、合同和协调管理 |
| 技术负责人 | 水利水电工程相关专业中级及以上职称 | 负责技术方案、技术交底、变更管理和质量技术控制 |
| 专职安全员 | 安全生产考核合格证 | 负责安全检查、隐患整改、教育培训和应急管理 |
| 质量员 | 岗位证书或相关专业资格 | 负责工序质量检查、隐蔽验收和质量资料 |
| 施工员 | 岗位证书 | 负责现场施工组织、班组协调和进度落实 |
| 材料员 | 岗位证书 | 负责材料采购、进场验收和台账管理 |
| 资料员 | 岗位证书 | 负责施工资料、验收资料和归档管理 |
| 测量员 | 测量相关证书或经验 | 负责控制网复核、施工放样和测量记录 |
| 试验员 | 试验检测相关资格 | 负责原材料、混凝土、土方压实等检测配合 |

## 设计类项目人员配置

| 岗位 | 专业方向 | 主要职责 |
| --- | --- | --- |
| 项目负责人 | 水利工程高级工程师或注册资格 | 统筹设计进度、质量和成果交付 |
| 水工专业负责人 | 水工结构 | 负责大坝、溢洪道、放水设施等设计 |
| 水文专业负责人 | 水文水资源 | 负责水文复核、洪水计算和调洪分析 |
| 地质专业负责人 | 工程地质 | 负责地质勘察、基础评价和处理建议 |
| 造价专业负责人 | 工程造价 | 负责编制概算、预算和投资控制 |
| 信息化专业负责人 | 自动化/通信 | 负责监测、视频、调度和平台设计 |

## 投标使用提示

- 人员配置必须与招标文件资格条件、评分办法和项目规模匹配。
- 项目经理、总监、项目负责人等关键人员应提供证书、社保和类似业绩证明。
- 如果招标文件要求不得更换关键人员，应在投标承诺中明确响应。
