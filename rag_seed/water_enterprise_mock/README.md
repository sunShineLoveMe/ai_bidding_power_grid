# 水利行业脱敏模拟企业资料包

本目录用于模拟真实企业在“企业资信库、企业产品库、企业能力库”中的资料准备和上传流程。资料内容基于公开水利行业投标要求、资质要求和常见企业能力结构整理，不包含具体企业名称、证书编号、人员身份证号、合同金额等敏感信息。

## 目录结构

```text
rag_seed/water_enterprise_mock/
├── 01_company_profiles/      # 脱敏企业画像
├── 02_qualification_library/ # 资信库模拟资料
├── 03_product_library/       # 产品库/服务库模拟资料
├── 04_capability_library/    # 能力库模拟资料
├── 05_upload_workflow/       # 模拟用户上传流程说明
├── source_notes.md           # 公开调研依据摘要
├── index.csv                 # 文件索引
└── index.jsonl               # 机器可读索引
```

## 使用方式

1. 先在系统中进入“企业资信库”，上传 `02_qualification_library/` 下的证照、人员、业绩和信用资料。
2. 再进入“企业产品库”，上传 `03_product_library/` 下的产品和服务资料。
3. 最后进入“企业知识库”或后续能力库，上传 `04_capability_library/` 下的施工组织、质量、安全、环保、售后和项目管理能力资料。
4. 用“水库除险加固投标需要准备哪些企业资料？”等问题验证 RAG 召回效果。

## 注意事项

- 本资料包为模拟数据，不得作为真实投标文件使用。
- 文件中的企业名称统一采用“某水利工程建设企业”“某水利设计咨询企业”等脱敏表达。
- 证书编号、人员姓名、合同编号、金额等均以占位符或合理合成字段表达。
- 如果后续用于演示，可继续补充脱敏 PDF、图片、证书扫描件和产品图片，以测试图文 RAG 能力。
