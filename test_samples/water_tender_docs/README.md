## 推荐测试顺序

1. 先上传 `05_伊犁州奎屯市东郊水库工程项目法人全过程质量检测_招标文件.pdf`，文件较小，适合快速验证上传、解析、AI 解读、章节大纲链路。
2. 再上传 `01_塔里木河流域希尼尔水库除险加固工程坝基防渗处理施工标_招标文件.pdf`，验证水库除险加固施工类项目。
3. 最后上传 `04_某水利工程施工标段_施工招标文件.pdf`，验证较长 PDF 的 MinerU 解析、分片质量和章节生成稳定性。
