# 电网行业 AI 智能标书系统 — 项目方案与资料需求

---

## 一、项目概述

### 1.1 产品定位

面向**电网行业投标企业**（设备供应商、工程承包商、服务商）的 AI 智能标书编制平台。

核心能力：招标文件上传 → AI 智能解读 → 自动生成标书大纲 → AI 编写全文 → 合规检查 → 正式 Word 导出，全流程 AI 辅助，企业私有知识库驱动。

### 1.2 目标客户

给国网、南网及地方电网公司投标的企业，包括但不限于：
- 输变电设备制造商
- 电力工程施工承包商
- 电缆/线材供应商
- 电力设计/咨询服务商
- 电力物资供应商

### 1.3 核心价值

| 痛点 | 解决方案 |
| --- | --- |
| 标书编写耗时长（通常 5～15 天） | AI 全文生成，1～2 小时出初稿 |
| 容易漏响应评分项导致丢分 | 智能合规检查，逐条追踪响应覆盖率 |
| 企业历史资料散落各处难以复用 | 企业私有知识库，AI 自动召回相关资料 |
| 格式排版反复调整 | 一键导出正式 Word，自动套用模板 |
| 新员工上手慢 | AI 辅助降低专业门槛 |

```
├─────────────┬─────────────┬─────────────┬───────────┤
│  招标解读    │  标书大纲    │  正文编写    │  合规检查  │

│  · 资格项提取 │  · 章节规划  │  · 知识库驱动 │  · 风险预警  │
│  · 风险项识别 │  · 篇幅分配  │  · 图文并茂  │  · 补强建议  │
├─────────────┴─────────────┴─────────────┴───────────┤
│                   企业私有知识库                        │
│  · 企业资质库  · 产品/设备库  · 历史业绩库  · 标准话术库  │
├─────────────────────────────────────────────────────┤
│                   正式文档导出                         │
│  · Word 标书导出  · 自动目录  · 模板套用  · 页码刷新    │
└─────────────────────────────────────────────────────┘
```

### 2.2 多租户 SaaS 模式

- **一个企业 = 一个账号**：注册即用，登录即进入自己的数据空间
- **数据严格隔离**：每家企业的知识库、项目、标书内容完全独立，互不可见
- **独立知识库**：每家企业维护自己的资质、业绩、产品、标准话术等私有数据
- **按需使用**：企业按实际使用量付费，无需购买服务器

### 2.3 部署方案

系统将部署在**阿里云**上，采用以下技术架构：

| 组件 | 方案 | 说明 |
| --- | --- | --- |
| 数据库 | 阿里云 RDS PostgreSQL | 企业数据安全存储 |
| 文件存储 | 阿里云 OSS | 招标文件、标书文档、图片资产 |
| AI 模型 | DeepSeek + 阿里云 DashScope | 国内模型，数据不出境 |
| 计算服务 | 阿里云 ECS | 稳定可靠 |

**数据安全保障**：
- 所有数据存储在国内阿里云节点
- 企业间数据严格隔离，应用层 + 数据库层双重防护
- 支持大客户私有化部署（数据完全在客户自己的服务器上）

## 三、实施计划

### 3.1 整体规划

项目分两期实施：

| 阶段 | 周期 | 目标 | 交付物 |
| --- | --- | --- | --- |
| **一期** | 6～8 周 | 电网行业单租户版本，交付首个客户使用 | 可独立部署的电网标书系统 |
| **二期** | 8～10 周 | 多租户 SaaS 版本，支持多家企业同时使用 | 阿里云 SaaS 平台 + 运营管理后台 |

### 3.2 一期：电网行业版本（6～8 周）

**目标**：让系统完整支持电网行业标书编制全流程。

**主要工作**：
1. 电网行业 AI 模型调优（招标解读、正文生成、合规检查）
2. 电网行业知识库建设（评分规则、资质要求、行业标准、废标情形）
3. 电网行业标书模板适配
4. 客户企业画像配置
5. 联调测试与交付

**验收标准**：客户能正常完成 招标文件上传 → AI 解读 → 大纲生成 → 全文编写 → 合规检查 → Word 导出 全流程，内容贴合电网行业要求。

### 3.3 二期：多租户 SaaS 平台（8～10 周）

**目标**：支持多家电网投标企业同时使用，具备商业化运营能力。

**主要工作**：
1. 企业注册/登录系统
2. 企业数据隔离（项目、知识库、文件完全独立）
3. 阿里云部署（RDS + OSS + ECS）
4. 运营管理后台（企业管理、用量统计、数据看板）
5. 计费体系准备

## 四、一期启动前需客户提供的资料清单

| 序号 | 资料名称 | 说明 | 数量要求 |

### 4.4 资料脱敏说明

我们理解企业资料的敏感性，以下是脱敏建议：

| 资料类型 | 脱敏方式 | 注意事项 |
| --- | --- | --- |
| 招标文件 | **无需脱敏**（招标文件本身是公开信息） | 直接提供原件 |
| 中标标书 | 金额替换为"XXX 万元"，人名替换为"张某某"，合同编号替换为"XXXX-XXX" | **请保留章节结构和正文逻辑完整** |
| 资质证书 | 可打马赛克遮挡证书编号和法人签名 | 保留证书类型和等级可见 |
| 业绩清单 | 金额可模糊为区间（如"500～1000 万"） | 项目名称和甲方名称建议保留 |

## 五、合作模式

### 5.1 一期合作

- **交付方式**：独立部署版本，部署在客户指定的服务器或我方提供的云服务器上
- **服务内容**：系统部署 + 电网行业适配 + 知识库初始化 + 使用培训
- **维护支持**：交付后提供 3 个月免费维护期

### 5.2 二期 SaaS 模式

- **使用方式**：在线注册，按需使用
- **计费方式**：按 AI 调用量计费（具体定价另行沟通）
- **数据安全**：企业数据严格隔离，支持随时导出全量数据
- **大客户选项**：支持私有化部署（数据完全在客户自己的服务器上）
