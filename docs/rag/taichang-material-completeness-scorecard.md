# 泰昌 MVP 资料完整性评分表

> 状态日期：2026-06-12  
> 适用主体：河北泰昌电力器材科技有限公司  
> 适用范围：泰昌企业事实资料、辽宁招标场景样本、正式 DOCX 图文导出、企业知识库问答和后续正式投标资料补齐。  
> 结论口径：本评分只判断“当前资料能否支撑系统生成和交付初稿”，不替代投标前的客户盖章、授权、有效期、目标省公司/批次/规格人工确认。

## 6. 使用边界

- 泰昌企业事实只能来自泰昌原始资料和已确认补充资料；河北豪乾参考稿不得作为泰昌资质、业绩、图片或能力事实。
- 辽宁资料只作为电缆保护管招标场景样本，不代表全国国网或其他省公司要求。
- 具体投标前必须以目标招标文件、澄清补遗、包号、规格和客户确认口径为准。
- 涉及身份证、社保、银行账户、财务、签章、公章和签名的资料，默认仅内部使用，不自动插入正式 DOCX。
- 结构化参数问答优先查泰昌参数层；没有结构化值时，不允许模型从图片或普通文本中猜数值。
