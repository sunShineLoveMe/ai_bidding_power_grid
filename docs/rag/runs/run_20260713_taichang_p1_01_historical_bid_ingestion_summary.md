## 4. 真实链路发现与修复

首次真实 `/api/knowledge/search/stream` 验证发现：CPVC“平均内径和壁厚”复合问题被同报告中的“承口平均内径 280.5 mm”抢占，导致管体平均内径和壁厚未同时进入最终上下文。

修复内容：

1. 产品族明确时改为硬过滤，CPVC 与 MPP 不再通过减分方式混入同一参数答案；
2. 查询未明确“承口”时，承口平均内径/承口壁厚不得替代管体平均内径/壁厚；
3. 同一报告、同一规格的多个结构化参数上下文在来源级去重时合并正文，不再只保留一行；
4. 复合参数问题存在明确参数词时，不再用“检验结果”泛词补入无关参数。

最终真实 stream：

- MPP 环刚度：`66.40 kN/m²`，报告 `2024100312005501712`；
- CPVC 平均内径：`250.2~250.4 mm`；
- CPVC 壁厚：`15.2~15.3 mm`；
- CPVC 报告：`2024100312005501713`；
- CPVC 原始召回和答案均不含承口平均内径 `280.5 mm`，也不含 MPP 报告号；
- 历史现状环境影响评估报告资产可召回，回答明确其是历史 Word 内嵌载体、不能直接作为正式投标附件或精确参数使用。
