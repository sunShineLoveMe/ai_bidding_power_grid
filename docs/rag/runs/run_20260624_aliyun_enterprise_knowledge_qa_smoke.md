## 3. 问答结果

### 3.1 泰昌有哪些资质证书？

结果：**FAIL**

正确表现：

- 能返回内容；
- 回答主体为河北泰昌电力器材科技有限公司；
- 没有引用辽宁招标要求或河北豪乾参考稿。

缺陷：

1. 页面已明确存在质量、环境、职业健康安全三份体系认证证书，但回答只明确列出质量管理体系认证，并声称其他证书类型不明确。
2. 来源优先引用《ESG环境社会公司治理报告》《绿色发展规划报告》，没有优先引用三份正式认证证书。
3. 回答声称泰昌产品“全部获得国家颁发的生产许可证”，当前展示来源不足以支撑该强结论，需要以正式许可证原件核验。
4. 回答把正式入库证书描述为“脱敏样例”“排版占位”，与客户原始企业事实资产的使用口径冲突。
5. 页面直接展示 `certification`、`taichang_certification_*` 等内部命名。

### 3.2 泰昌 CPVC 电缆保护管有哪些检验报告？

结果：**基本通过，存在展示缺陷**

正确表现：

- 返回一份 CPVC 电缆保护管检验报告；
- 报告编号为 `2024100312005501713`；
- 规格为 `DS 250×15×6000 SN16 PVC-C`；
- 来源为泰昌产品结构化参数；
- 明确限制结论只适用于泰昌和该规格；
- 未串用辽宁招标要求。

缺陷：

1. 回答正文直接展示内部接口路径 `/api/knowledge/assets/`。
2. 来源标签重复显示“泰昌产品结构化参数”。
3. “报告有效期通常为 1-2 年”属于泛化判断，不应在原件未明确时作为事实提示，建议改为“以招标要求及报告原件为准”。

### 3.3 泰昌有哪些企业证明材料？

结果：**FAIL**

正确表现：

- 能返回社保证明、体系认证、环保报告等内容；
- 回答主体为泰昌；
- 没有引用辽宁或河北豪乾资料。

缺陷：

1. 企业知识库页面已经存在“基础证照”资料，但回答错误声称当前缺少营业执照、安全生产许可证、开户许可证等基础资质。
2. 把“泰昌社保证明”错误归入“生产制造能力内部专用图片资产目录”和“试验检测能力内部专用图片资产目录”。
3. 回答将真实入库图片统一描述为“脱敏示意图”，并建议正式标书替换原件，和当前客户原始资产定位冲突。
4. 直接展示 `production_capacity`、`certification`、`taichang_*` 等内部枚举和文件名。
5. 参考来源摘要直接暴露 `parsed_outputs/power_grid_customer_corpus/...` 内部服务器路径。
6. 回答中的企业统一社会信用代码和地址文本存在 OCR 可疑内容，应以营业执照原件或结构化企业档案为准，不能直接作为确定事实输出。

## 4. 缺陷清单

| 优先级 | 缺陷 | 影响 | 建议处理 |
| --- | --- | --- | --- |
| P0 | 资质问答未优先命中正式体系认证证书 | 可能遗漏企业真实资质，影响资信响应 | 对资质/证明类问题增加 `doc_role/category_label/source_domain` 硬过滤和确定性来源优先级 |
| P0 | 企业证明问答错误声称缺少已入库基础证照 | 可能在标书中形成错误缺口或错误补资料建议 | 先检索基础证照和企业档案，再生成缺口结论；无证据不得声明“缺少” |
| P0 | 社保证明被错误归类为生产制造/试验检测能力 | 企业事实类型混乱，可能导致章节误配图 | 修复资产目录 metadata 和检索分类，社保只归入企业证明/人员社保资料 |
| P1 | 内部枚举、文件名和服务器路径暴露 | 客户可见信息不专业，泄露内部实现 | 统一经过中文展示名映射；过滤 `taichang_*`、snake_case、`parsed_outputs/`、API 内部路径 |
| P1 | 正式企业资产被描述为脱敏样例或占位图 | 降低资料可信度，影响正式标书引用 | 根据 metadata 区分客户原件、全页渲染和脱敏样例，不得统一追加脱敏声明 |
| P1 | 来源排序未按确定性文件优先 | 回答依赖宣传材料而非证书原件 | 正式证书/结构化参数 > 原始报告 > 企业宣传资料 > 图片目录 |
| P2 | 来源标签重复、正文暴露内部 API 路径 | 页面观感和可读性较差 | 来源按文件去重，隐藏接口路径和重复标签 |

## 5. 验收结论

本轮 3 条问题：

- PASS：0；
- 基本通过：1；
- FAIL：2。

企业知识库接口和模型链路可用，但企业事实的来源选择、缺口判断和中文展示尚未达到客户主流程冒烟条件。当前应先修复 P0/P1 问答缺陷，再进入最小标书主流程，避免错误企业事实进入章节正文和 DOCX。

## 6. 复测口径

修复后重新执行相同 3 条问题，并满足：

1. 资质问题明确返回质量、环境、职业健康安全体系认证，来源优先指向对应证书原件；
2. CPVC 问题保持报告编号、规格和结构化参数正确，不展示内部 API 路径；
3. 企业证明问题不得错误声明缺少已入库基础证照；
4. 社保证明不得归类为生产制造或试验检测能力；
5. 页面不出现 `taichang_*`、`production_capacity`、`certification`、`parsed_outputs/`；
6. 同一文件或报告只显示一条合并来源；
7. 回答不引用辽宁招标要求或河北豪乾参考稿作为泰昌企业事实。
