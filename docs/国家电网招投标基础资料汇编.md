# 国家电网招投标基础资料汇编

> 本文档汇总国家电网招投标相关的政策法规、标准体系、采购流程、供应商管理、评标方法、设备分类、技术趋势等核心知识，用于支撑AI自动化标书系统的知识库建设。

## 三、采购模式与流程

### 3.1 国网采购模式

| 采购模式 | 定义 | 适用场景 | 特点 |
|---------|------|---------|------|
| 集中招标 | 国网总部统一组织的大宗物资和服务采购 | 大型设备、批量物资 | 规模大、周期长、竞争激烈 |
| 协议库存 | 通过招标确定供应商和价格，按需分批供货 | 标准化物资、常用设备 | 简化流程、提高效率 |
| 框架招标 | 建立供应商框架，按需选择和分配订单 | 通用物资、技术服务 | 灵活性高、响应快速 |
| 竞争性谈判 | 非招标方式，通过谈判确定供应商 | 紧急采购、技术复杂项目 | 流程简化、周期短 |
| 单一来源采购 | 只有一家供应商可提供的采购 | 专利产品、专有技术 | 无需竞争、直接采购 |
| 询价采购 | 通过询价比较确定供应商 | 标准化物资、小额采购 | 流程简单、效率高 |

### 3.3 关键时间节点

| 环节 | 时间要求 | 注意事项 |
|------|---------|---------|
| 招标文件发售 | 投标截止日前不少于5个工作日 | 注意购买时间和方式 |
| 投标文件递交 | 招标文件规定的截止时间前 | 注意密封和标记要求 |
| 投标有效期 | 从投标截止日起算，一般90-180天 | 注意有效期覆盖评标和签约期 |
| 投标保证金 | 一般不超过项目估算价的2% | 注意缴纳时间和方式 |
| 开标时间 | 与投标截止时间同一时间 | 注意开标地点和程序 |
| 评标时间 | 一般不超过30个工作日 | 复杂项目可适当延长 |
| 中标公示 | 评标结束后不少于3日 | 注意公示内容和异议处理 |
| 签订合同 | 中标通知书发出后30日内 | 注意合同条款与投标文件一致 |

## 五、评标方法

### 5.1 综合评估法

综合评估法是国网招标最常用的评标方法，按以下权重进行评分：

| 评分项目 | 权重范围 | 评分内容 |
|---------|---------|---------|
| 技术评分 | 40%-60% | 技术方案、技术参数、性能指标、技术创新 |
| 商务/价格评分 | 30%-50% | 投标价格、付款条件、交货期、售后服务 |
| 信誉评分 | 10%-20% | 业绩、资质、信誉、履约能力 |

### 5.2 技术评分细则

| 评分项 | 分值 | 评分标准 |
|-------|------|---------|
| 技术方案完整性 | 20-30分 | 方案是否完整、是否符合招标要求 |
| 技术参数符合性 | 30-40分 | 主要技术参数是否满足或优于要求 |
| 技术创新 | 10-15分 | 是否有技术创新点、先进性如何 |
| 施工组织设计 | 15-20分 | 施工方案的合理性、可行性 |
| 质量保证措施 | 10-15分 | 质量保证体系和措施的完善程度 |
| 安全保证措施 | 10-15分 | 安全保证体系和措施的完善程度 |
| 工期保证措施 | 5-10分 | 工期保证措施的合理性 |
| 售后服务方案 | 5-10分 | 售后服务的承诺和保障措施 |

### 5.3 价格评分方法

| 方法 | 计算公式 | 适用场景 |
|------|---------|---------|
| 最低价法 | 价格得分 = (最低价/投标价) × 价格权重 × 100 | 标准化物资、通用设备 |
| 基准价法 | 价格得分 = 1 - |投标价-基准价|/基准价 × 价格权重 × 100 | 技术复杂项目 |
| 综合评分法 | 价格得分 = 价格权重 × 100 × (1 - (投标价-最低价)/最低价) | 综合评估项目 |

### 5.4 常见否决投标情形

| 情形类别 | 具体情形 | 后果 |
|---------|---------|------|
| 格式问题 | 未按招标文件格式编制、装订不符合要求 | 否决投标 |
| 资质问题 | 资质不符合要求、资质过期、资质造假 | 否决投标 |
| 报价问题 | 报价超出预算、报价明显不合理、报价错误 | 否决投标 |
| 时间问题 | 未在截止时间前递交、逾期送达 | 否决投标 |
| 签章问题 | 未按要求签字盖章、授权委托书缺失 | 否决投标 |
| 保证金问题 | 未按要求缴纳保证金、保证金不足 | 否决投标 |
| 实质性响应 | 未对实质性要求做出响应 | 否决投标 |
| 弄虚作假 | 提供虚假资料、业绩造假 | 否决投标并列入黑名单 |

| 杆塔 | 钢管杆、角钢塔、水泥杆 | 承载能力、防腐性能、使用寿命 |

### 6.2 核心技术指标

| 设备 | 关键指标 | 典型要求 |
|------|---------|---------|
| 变压器 | 空载损耗 | 不超过标准值的105% |
| 变压器 | 负载损耗 | 不超过标准值的105% |
| 变压器 | 局部放电量 | ≤100pC (220kV及以上) |
| 开关设备 | 额定短路开断电流 | 根据系统要求确定 |
| 开关设备 | 机械寿命 | ≥10000次 |
| 电缆 | 局部放电量 | ≤5pC (110kV及以上) |
| 电缆 | 绝缘电阻 | ≥1000MΩ·km |
| 保护装置 | 动作时间 | ≤30ms (主保护) |
| 保护装置 | 测量精度 | ≤0.5级 |
| 电表 | 精度等级 | 0.2S级、0.5S级、1级 |

### 7.2 编制注意事项

| 要点 | 具体要求 | 常见错误 |
|------|---------|---------|
| 格式规范 | 严格按照招标文件格式编制 | 格式混乱、装订不符合要求 |
| 内容完整 | 响应招标文件所有要求 | 遗漏实质性要求、响应不完整 |
| 语言准确 | 专业术语准确、表述清晰 | 术语错误、表述模糊 |
| 数据一致 | 各处数据相互一致 | 前后矛盾、数据不一致 |
| 签章齐全 | 按要求签字盖章 | 遗漏签章、签章位置错误 |
| 时效性 | 资质证书在有效期内 | 资质过期、证书失效 |
| 针对性 | 针对项目特点编制 | 内容通用、缺乏针对性 |
| 竞争性 | 突出优势、体现竞争力 | 内容平淡、无亮点 |

### 7.3 常见扣分项

| 扣分项 | 扣分原因 | 预防措施 |
|-------|---------|---------|
| 技术方案不完整 | 遗漏招标文件要求的内容 | 逐项核对招标文件要求 |
| 技术参数不满足 | 主要参数未达到要求 | 提前确认产品参数 |
| 施工方案不合理 | 施工方案缺乏可行性 | 结合现场实际编制 |
| 质量措施不具体 | 措施空洞、缺乏可操作性 | 制定具体的质量控制点 |
| 安全措施不完善 | 安全措施覆盖不全 | 识别所有安全风险 |
| 业绩证明不足 | 业绩数量或类型不满足 | 提前准备业绩证明材料 |
| 人员配置不当 | 人员资质或数量不满足 | 合理配置项目人员 |
| 报价不合理 | 报价过高或过低 | 科学测算成本和利润 |
