# 国家电网单企业测试环境阿里云费用评估

> 评估日期：2026-05-18  
> 评估对象：现有 AI 招投标系统改造为国家电网招投标企业使用后的第一期测试环境  
> 部署目标：单企业、测试环境、最多 3 个招投标业务场景，不按多租户或高可用生产集群估算  
> 费用承担：客户承担阿里云资源、存储、在线 API 调用费用  
> 重要说明：以下为测试环境预算口径，正式下单价格以阿里云控制台、DeepSeek、阿里云百炼、MinerU 控制台账单为准

---

## 1. 结论

建议测试环境放在阿里云，第一期不要做复杂高可用。按“能测试真实业务链路”来估算，客户每月需要预留：

| 档次 | 适用阶段 | 云资源月费 | 在线 API 预计实际消耗 | API 风险预留池 | 月度合计建议 | 预充值建议 |
|---|---|---:|---:|---:|---:|---:|
| A. 低配验证档 | 内部演示、少量样本跑通 | 800-1,500 元 | 300-1,000 元 | 1,000-2,000 元 | **1,200-2,500 元/月** | 0.5-1 万 |
| B. 标准测试档 | 客户核心人员试用、3 个场景并行测试 | 1,800-3,500 元 | 800-3,000 元 | 3,000-5,000 元 | **3,000-6,500 元/月** | 1-3 万 |
| C. 增强测试档 | 高频测试、大文件、扫描件较多、接近准生产 | 4,000-8,000 元 | 3,000-10,000 元 | 10,000-20,000 元 | **7,000-18,000 元/月** | 3-5 万 |

我的建议是：**第一期按 B 档标准测试档准备预算**。这里的“月度合计建议”按预计实际消耗估算；“API 风险预留池”不是每月一定花掉的钱，而是客户账号里建议保留的充值余额，用来应对扫描件、大文件、重复生成和集中测试。

## 2. 当前系统对测试环境的实际依赖

当前项目不是纯前端或简单后台，测试环境至少需要覆盖以下组件：

| 类型 | 当前系统依赖 | 测试环境处理方式 |
|---|---|---|
| Web 前端 | React 18 / Vite / Ant Design / Tiptap | 构建后由 Nginx 或 Flask 静态服务提供 |
| 后端 API | Flask API | 部署在 ECS，建议用 systemd / Docker / Supervisor 托管 |
| 数据库 | PostgreSQL + pgvector，当前代码使用 Supabase 结构 | 测试期可用阿里云 RDS PostgreSQL 或自建 PostgreSQL |
| 文件存储 | 招标文件、生成 DOCX、知识库、资信库、产品库 | 推荐迁移到 OSS；低配可先本地磁盘 + 定期备份 |
| 文档解析 | 原生解析 + MinerU OCR / 版面解析 | 在线调用 MinerU；大扫描件费用波动最大 |
| AI 生成 | DeepSeek V4 Pro / Flash | DeepSeek API，按 token 计费 |
| 向量与重排 | DashScope text-embedding-v4 / qwen3-rerank | 阿里云百炼 API，按 token 计费 |
| Word 导出 | python-docx + LibreOffice headless | ECS 安装 LibreOffice，建议单独留 CPU/内存余量 |
| 在线编辑，可选 | ONLYOFFICE | 测试期可不启用；若启用建议单独容器或单独 ECS |

## 3. 三档测试环境配置

### A 档：低配验证档

适合在项目初期跑通链路、内部演示、少量真实文件验证。

| 资源 | 建议配置 | 月费估算 |
|---|---|---:|
| ECS 应用服务器 | 1 台，4 核 8G，100-200GB 云盘 | 500-900 元 |
| 数据库 | 同机自建 PostgreSQL + pgvector | 0 元新增成本 |
| 文件存储 | 本地磁盘为主，OSS 100GB 以内备份 | 20-100 元 |
| 公网访问 | EIP / 固定带宽 3-5Mbps 或按流量 | 100-300 元 |
| 域名 / HTTPS | 域名已有则只配免费证书 | 0-100 元 |
| 监控 / 日志 | 云监控基础能力 + 本地日志 | 0-100 元 |
| 备份 | 云盘快照 / 手动备份 | 100-300 元 |
| **云资源小计** |  | **800-1,500 元/月** |

优点：便宜、搭建快。  
缺点：数据库、应用、文件都在一台机器上，测试高峰时容易互相影响；不建议客户多人长期试用。

### B 档：标准测试档

适合客户核心人员正式试用，覆盖最多 3 个国家电网招投标场景，是第一期最推荐方案。

| 资源 | 建议配置 | 月费估算 |
|---|---|---:|
| ECS 应用服务器 | 1 台，8 核 16G，200-300GB 云盘 | 900-1,800 元 |
| 数据库 | 阿里云 RDS PostgreSQL Serverless 或 2 核 4G RDS，100-200GB | 500-1,200 元 |
| OSS 存储 | 300-500GB，存招标文件、知识库、导出文件 | 50-200 元 |
| 公网访问 | EIP / 5-10Mbps 或按量流量 | 200-600 元 |
| 反向代理 / HTTPS | Nginx + 免费证书，必要时备案域名 | 0-200 元 |
| 监控 / 日志 | 云监控 + 简单日志服务 | 100-300 元 |
| 备份 | RDS 备份 + OSS / 云盘快照 | 200-700 元 |
| **云资源小计** |  | **1,800-3,500 元/月** |

优点：应用、数据库、文件存储边界清晰，便于排障和迁移；费用仍然可控。  
缺点：不是高可用架构，单 ECS 故障仍会影响测试。

### C 档：增强测试档

适合客户高频试用、扫描件较多、大文件较多，或希望测试环境接近准生产。

| 资源 | 建议配置 | 月费估算 |
|---|---|---:|
| ECS 应用服务器 | 1 台 8 核 16G 应用机 + 1 台 4 核 8G 任务/解析机 | 1,800-3,500 元 |
| 数据库 | RDS PostgreSQL 4 核 8G 或 Serverless 较高 RCU，200-500GB | 1,000-2,500 元 |
| OSS 存储 | 1TB 左右，含资料库、解析产物、导出文件 | 150-500 元 |
| 公网访问 | EIP / 10Mbps 以上，或 ALB + EIP | 500-1,500 元 |
| 监控 / 日志 | 云监控 + 日志服务，保留 30 天 | 300-800 元 |
| 备份 | RDS 自动备份 + OSS 生命周期 + 云盘快照 | 300-1,000 元 |
| 安全加固 | WAF / 安全组策略 / 访问白名单，按需启用 | 0-1,000 元 |
| **云资源小计** |  | **4,000-8,000 元/月** |

优点：更接近后续生产部署，便于做压力测试和客户集中试用。  
缺点：费用明显上升，第一期如果只是业务验证，没有必要一开始就上。

## 4. 在线 API 费用估算

在线 API 是测试环境费用波动最大的部分，但不能简单理解为每月一定会花很多钱。按当前 DeepSeek V4 Flash / Pro 的 token 单价，纯 LLM 生成本身通常不会特别贵；真正导致费用上升的是扫描件 OCR、MinerU 解析、大文件分段解读、客户反复上传和反复全文生成。

### 4.1 费用构成

| API 类型 | 用途 | 计费影响因素 | 估算口径 |
|---|---|---|---|
| DeepSeek V4 Pro | 招标解读、大纲、合规复核等复杂推理 | 招标文件长度、分段数量、重复生成次数 | 按输入 / 输出 token 计费 |
| DeepSeek V4 Flash | 正文生成、补写、知识库问答、追问建议 | 章节数量、生成长度、补写次数 | 按输入 / 输出 token 计费 |
| DashScope Embedding | 知识库、资信库、产品库向量化 | 上传资料数量、资料长度、更新频率 | 按输入 token 计费 |
| DashScope Rerank | 知识库检索重排 | 检索次数、候选片段数量 | 按输入 token 计费 |
| MinerU | PDF / 图片 / Office 文件解析 | 页数、文件大小、扫描件比例、版式复杂度 | 以 MinerU 控制台实际价格为准 |

### 4.2 按测试强度估算

| 测试强度 | 假设用量 | API 预计实际消耗 |
|---|---|---:|
| 低频验证 | 每月 5-10 个招标文件，少量知识库资料，主要演示 | 300-1,000 元/月 |
| 标准测试 | 每月 15-30 个招标文件，3 个业务场景，各场景反复生成和修订 | 800-3,000 元/月 |
| 高频测试 | 每月 50 个以上文件，大量扫描件，大量全文反复生成 | 3,000-10,000 元/月 |

如果客户上传的文件大多是文字型 PDF 或 DOCX，且不是反复全量生成，B 档测试期 API 实际消耗大概率在 **1,000-3,000 元/月**。如果扫描件比例高、OCR 频繁失败重试，才需要按更高风险池准备。

### 4.3 单个标书任务的粗略 API 成本

下面按一次“上传解析 -> 招标解读 -> 大纲 -> 章节正文 -> 合规检查 -> Word 导出前修订”的完整流程估算。

| 文件类型 | 单次任务 API 成本 | 说明 |
|---|---:|---|
| 普通文本型 PDF / DOCX，50-100 页 | 10-80 元/次 | 主要成本在 LLM 解读和正文生成 |
| 较大 PDF，100-200 页 | 50-200 元/次 | 分段解读、补写、合规检查次数增加 |
| 扫描件 / 图片型 PDF，100-200 页 | 100-500+ 元/次 | MinerU/OCR 成本和失败重试会明显放大 |

所以，在线 API 不建议对客户说成“固定月费”。更准确的说法是：**正常测试预计消耗不高，但客户账号里要留一笔 API 风险余额**。这笔余额主要防止测试期集中跑大文件、扫描件和反复生成时临时欠费中断。

## 5. 推荐采购方案

### 5.1 第一阶段推荐

建议客户第一期直接采用 **B 档标准测试档**：

| 项目 | 建议 |
|---|---|
| 云资源 | 按 2,000-3,500 元/月准备 |
| 在线 API 预计实际消耗 | 按 1,000-3,000 元/月准备 |
| API 风险预留池 | 客户账号保留 3,000-5,000 元余额 |
| 月度总预算 | 按 3,000-6,500 元/月准备 |
| 首次预充值 | 1-3 万 |
| 观察周期 | 1-2 个月 |

这样可以支撑：

- 单企业测试；
- 3 个国家电网招投标场景；
- 15-30 个真实招标文件的端到端测试；
- 企业资信库、产品库、知识库的初步导入；
- 多轮 AI 解读、章节生成、Word 导出测试；
- 基础备份、监控、日志和故障排查。

### 5.2 不建议一开始选择 A 档的情况

如果客户有以下情况，不建议用 A 档：

| 情况 | 原因 |
|---|---|
| 客户多人同时测试 | 单机资源容易被解析和生成任务打满 |
| 扫描件、图片 PDF 很多 | OCR 任务耗时长，失败重试多 |
| 要让客户领导正式体验 | 页面响应和任务稳定性更重要 |
| 要持续积累知识库、产品库 | 本地磁盘和同机数据库后期迁移麻烦 |

### 5.3 什么时候升级到 C 档

出现以下任一情况，再升级到 C 档：

| 触发条件 | 升级动作 |
|---|---|
| 每月处理 50 个以上招标文件 | 增加任务/解析 ECS |
| 大文件解析经常拖慢页面 | 应用机和任务机拆分 |
| 客户开始接近生产试运行 | RDS 升级，增加备份、监控、安全策略 |
| 多人集中测试，排队明显 | 扩容 ECS / 拆分任务队列 |

## 6. 客户沟通口径

可以对客户这样表达：

> 第一阶段建议把测试环境全部放到阿里云，由客户承担云资源和在线 API 实际消耗。按单企业、最多 3 个国网投标场景的测试强度，推荐准备标准测试环境，每月云资源和 API 的实际消耗预计约 3,000-6,500 元，其中在线 API 正常预计约 1,000-3,000 元/月。首次建议客户账号预充值 1-3 万，其中一部分作为 MinerU/OCR、大文件、重复生成的风险余额。若只是内部演示，可以压到 1,200-2,500 元/月；若进入高频试用或准生产，再提升到 7,000-18,000 元/月。

合同或报价单中建议明确：

- 云服务器、数据库、OSS、带宽、域名、证书、短信或其他云服务由客户账号购买并承担；
- DeepSeek、阿里云百炼、MinerU 等在线 API 由客户开通账号、充值并承担实际消耗；
- 我方负责部署、配置、联调、基础监控和费用观察建议；
- 测试环境不是高可用生产环境，不承诺生产 SLA；
- 如果测试期用量超过预算，客户需追加充值或降低测试频率。
