# 技术标 / 商务标分册整改 TODO

## 背景

当前系统已经打通了招标文件上传、MinerU/OCR 解析、招标解读、章节大纲生成、章节正文生成、企业知识库 RAG、资信库/产品库图片资产和 DOCX 导出等核心链路。

但目前产品主线仍按“整本标书”统一处理。系统虽然会在章节中生成“资格审查资料、商务响应文件、技术响应文件、报价文件及工程量清单”等内容，但这些只是普通章节，没有被建模为真实招投标业务里的分册结构。

从实际投标流程看，一份投标文件通常需要区分：

- 技术标：施工组织设计、技术响应、质量安全环保、进度计划、资源配置、设备方案等。
- 商务标：投标函、授权委托书、商务条款响应、偏离表、承诺函、合同条款响应等。
- 资格文件：营业执照、资质证书、安全生产许可证、人员证书、业绩、信誉声明等。
- 报价文件：工程量清单、报价汇总、分项报价、单价分析等。
- 附件册：证照扫描件、产品图片、图纸、业绩证明、其他证明材料等。

本 TODO 用于把当前“统一章节生成工具”逐步升级为“按真实投标分册组织的标书编制系统”。

## 总体目标

- [x] 让用户在主页和工作台中清楚看到技术标、商务标两个真实投标包；资格、报价、附件作为商务标内部资料类型保留。
- [x] 让 AI 在章节大纲生成阶段自动识别本项目实际需要的投标文件组成。
- [x] 让每个章节具备明确的分册归属，支持按分册生成、筛选、检查和导出。

- [x] 让最终导出的 Word 支持整本导出和分册导出。
