# SL2655 项目规则与泰昌资料覆盖差距表

> 项目：SL2655 新疆 MPP 包
> 结论：可用于规则与缺口验收；当前不得作为正式成稿正向样本

## 1. 项目规则

| 规则 | 招标文件依据 | 系统处理要求 |
| --- | --- | --- |
| 资格预审继承 | 投标人须知前附表 3.1.1：对应预审标段的资格预审申请文件作为投标文件的一部分 | 不重复要求整套预审资料，不把“未重复上传”误判为缺失 |
| 允许补充范围受限 | 3.1.1：仅接受除供货业绩外的规定支持证明材料更新或补充 | 只开放招标明确允许的补充项；供货业绩不得借补充文件绕过预审口径 |
| 到期资料需更新 | 3.1.1：预审时提供的资质证书、试验报告在投标截止前到期时需提供新材料 | 有效期检查必须覆盖投标截止日 |
| 价格文件按包 | 第六章投标文件格式目录 | 报价和投标函附件按包处理，不由系统虚构价格 |
| 商务/技术文件按分标 | 第六章投标文件格式目录 | 商务标、技术标按分标编制，防止包级数据串入其他分标 |

| 固定格式不得实质修改 | 投标人须知前附表 3.7.3 | 招标文件提供的表单优先保留结构，不用历史稿改写表头和签章位置 |

## 3. 必须补充或确认的资料

1. 泰昌 MPP 公称内径 200 mm、公称壁厚 14.0 mm 对应的有效检验报告或型式试验报告。
2. 报告或其他正式依据中可支撑断裂伸长率不低于 200% 的实测值/保证值。
3. 泰昌是否具备 SL2655 对应联合资格预审资格的明确确认。
4. 如使用更新资料，确认其主体、产品、规格、报告编号、有效期和投标截止日均一致。

## 4. 门禁结论

当前状态为 `PRODUCT_FAMILY_MATCHED_BUT_SPEC_NOT_COVERED`。系统应允许生成缺口报告和内部草稿，但必须阻断正式技术标/商务标成稿导出，不得使用以下方式绕过：

- 把 250×22 报告写成覆盖 200×14；
- 只比较环刚度数值而忽略报告规格；
- 把“完全响应”作为投标保证值；
- 用 CPVC、N-HAP、UPVC 或其他企业报告替代；
- 因历史标书存在某章节，就把本批次不适用章节带入目录。
