## 三、人工复核重点

461 条人工候选按来源标书、章节、证据类型、产品族和目标库合并为 65 个证据组。主要风险如下：

- 142 条视觉疑似重复、5 条文本疑似重复，必须查看原件确认；
- 2 条属于同一既有证据的不同载体，不得新建重复业务主记录；
- 32 条敏感资料、1 条受限资料，默认不能通过本批审批生成入库候选；
- 3 条职业健康安全管理体系证书候选已明确标记“延后补证”，历史证书于 2026-06-18 到期，禁止正式引用；
- 12 条产品参数表候选即使获批，也只能进入结构化抽取流程，不得作为普通文本/图片直接入库；
- 检验报告、校准证书、证书和财务资料必须核对编号、产品/规格、日期、有效期和完整原件；
- 连续内嵌页必须按完整报告或证据包审核，不得把几十页拆成几十个业务资产。

## 五、程序门禁

审批处理脚本：[`prepare_taichang_p0_06_asset_review.py`](../../scripts/rag/prepare_taichang_p0_06_asset_review.py)

执行审批表校验：

```bash
.venv/bin/python scripts/rag/prepare_taichang_p0_06_asset_review.py \
  --apply-decisions "docs/development/taichang-bid-v1-data/p0_06_review/泰昌历史标书资产增量入库审批表.xlsx"
```

以下情况会拒绝生成入库候选：

- 审批表候选编号被删除、增加或重复；
- 未填写复核人、复核日期或原始证据核验；
- 去重结论仍为重复或待进一步核验；
- 产品事实缺少产品族或未确认产品边界；
- 证书、报告等未确认有效性；
- 受限/敏感资料试图通过普通审批直接入库；
- 正式资产缺少独立原始证据文件或仅把历史标书本身作为原件；
- 中文标题包含内部枚举、解析路径、UUID、长哈希、`页面_`、`原图` 等禁用内容；
- 产品参数表试图绕过结构化抽取直接成为普通资产。
