# 泰昌历史标书资产 P0-06 分级接收与异常复核报告

## 一、执行结论

泰昌主动提供《技术补充文件》《商务补充文件》用于系统整理和历史标书复用，已经构成对这两份来源文件的处理授权。因此，系统不再要求资料管理人员逐页“批准来源”，而是按风险分级处理：

- 低风险、来源明确、不包含证照有效期、财务、人员、合同、精确参数等强时效事实的资料，自动接收为 `knowledge_only`；
- 证照、财务、人员、合同、检验报告、参数值、疑似重复、敏感资料等异常项继续人工复核；
- 精确重复项关联已有资产，同一证据不同载体关联同一证据包，不重复建业务主记录；
- 自动接收不等于已写数据库，也不等于 `formal_bid_ready`，更不允许直接进入正式标书。

## 二、自动接收范围

169 条自动接收项均来自泰昌技术标中的 Word 内嵌媒体，分布为：

| 证据类型 | 数量 | 使用边界 |
| --- | ---: | --- |
| 绿色低碳资料 | 112 | 仅作泰昌内部知识资料，精确数值仍须回溯原件 |
| 企业能力资料 | 35 | 仅作能力描述和写作参考，不替代正式证据 |
| 生产制造能力 | 22 | 仅作工艺、生产环境等知识资料，不直接作为正式配图 |

自动接收规则仅覆盖工艺流程、工序控制、生产制造环境、试组装环境、绿色低碳、ESG、三废治理、绿色发展及智能制造等低风险章节，并显式排除标题或章节中含有证书、凭证、查询、绩效评价、股权、合同、中标、授权、人员、审计、保证金等内容的候选。

这些记录统一标记：

```text
source_domain=enterprise_fact
quality_tier_after_review=knowledge_only
review_status_after_review=policy_auto_accepted
allowed_for_bid=false
formal_bid_ready=false
ingestion_action=extract_word_media_as_knowledge_only
ingestion_readiness=ready_for_extraction_and_validation
```

## 四、异常人工复核重点

290 条异常候选按来源标书、章节、证据类型、产品族和目标库合并为 60 个证据组。主要风险如下：

- 142 条视觉疑似重复、5 条文本疑似重复，必须查看原件确认；
- 32 条敏感资料、1 条受限资料，不能通过普通审批直接入库；
- 3 条职业健康安全管理体系证书候选已标记“延后补证”，历史证书于 2026-06-18 到期；
- 12 条产品参数表即使获批，也只能进入结构化抽取流程；
- 检验报告、校准证书、体系证书和财务资料必须核对编号、产品/规格、日期、有效期和完整原件；
- 连续内嵌页必须按完整报告或证据包审核，不得逐页建立业务主记录。

## 五、复核工作簿

工作簿：[`泰昌历史标书资产增量入库审批表.xlsx`](./taichang-bid-v1-data/p0_06_review/泰昌历史标书资产增量入库审批表.xlsx)

工作表包括：

1. `审批说明`：数量、规则和数据边界；
2. `证据分组`：60 个异常证据组总览；
3. `系统自动接收`：169 条无需逐项审批的低风险知识资料；
4. `异常候选复核`：290 条需要人工确认的风险项；
5. `自动阻断与仅参考`：437 条关联、阻断或结构参考记录。

人工审批结论支持：批准为知识资料、批准为正式资产、延后补证、禁止入库、保留历史参考。人工批准仍必须填写去重结论、原始证据核验、产品边界、有效性、正式展示质量、复核人和复核日期等必要字段。

## 六、程序门禁

处理脚本：[`prepare_taichang_p0_06_asset_review.py`](../../scripts/rag/prepare_taichang_p0_06_asset_review.py)

重新生成分级接收结果：

```bash
PYTHONPATH=. .venv/bin/python scripts/rag/prepare_taichang_p0_06_asset_review.py
```

应用异常复核结论：

```bash
PYTHONPATH=. .venv/bin/python scripts/rag/prepare_taichang_p0_06_asset_review.py \
  --apply-decisions "docs/development/taichang-bid-v1-data/p0_06_review/泰昌历史标书资产增量入库审批表.xlsx"
```

以下情况仍会拒绝人工批准：

- 工作簿候选编号被删除、增加或重复；
- 未填写复核人、复核日期或原始证据核验；
- 去重结论仍为重复或待进一步核验；
- 产品事实缺少产品族或未确认产品边界；
- 证书、报告等未确认有效性；
- 受限/敏感资料试图通过普通审批直接入库；
- 正式资产缺少独立原始证据文件，或仅把历史标书本身作为原件；
- 中文标题包含内部枚举、解析路径、UUID、长哈希、`页面_`、`原图` 等禁用内容；
- 产品参数表试图绕过结构化抽取直接成为普通资产。

## 七、边界与下一步

当前“批准 169、可进入后续处理 169”表示这些低风险候选已经通过来源授权和策略分级，可以进入 P1-01 的 Word 媒体提取、中文命名、质量检测和知识库增量入库准备；不表示 169 条已经写入知识库、产品库或资信库。
