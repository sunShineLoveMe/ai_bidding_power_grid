# 2026-06-27 知识库助手拖拽与底部文案回归

## 背景

客户反馈右下角“知识库助手”按钮固定在分页区域附近，影响页码和每页条数选择操作；同时底部页脚文案偏通用，需要更贴合国家电网投标系统的交付场景。

## 修改范围

- `frontend/src/components/layout/AppLayout.tsx`
  - 知识库助手按钮改为可拖拽浮动按钮。
  - 拖拽位置写入 `localStorage`，刷新后保留。
  - 拖拽范围限制在可视区内，并为底部页脚预留空间。
  - 拖拽不会误触发打开助手，只有非拖动点击才打开抽屉。
  - 底部文案替换为定制版：
    - 左侧：`国家电网投标智能工作台 · 招标解析 · 标书编制 · 正式检查`
    - 右侧：`企业资料本地可控 · 支持内网部署 · 面向真实投标交付`
- `frontend/src/index.css`
  - 助手按钮高度和宽度调整为 `48px`。
  - 图标缩小为 `16px`。
  - 增加拖拽态光标、阴影和视觉反馈。
