**2. 建设条件与工作界面**  
（1）项目单位：国网辽宁省电力有限公司及其下属各地市供电公司。  
（2）资金来源：企业自有资金，出资比例为100%，资金已落实。  
（3）交货地点：辽宁省内项目单位指定地点（包括但不限于各地市仓库、施工现场）。

（3）样品要求：投标人需按招标文件规定提交实物样品，样品经检测合格后方可参与后续评审。  
（4）质量追溯：中标人应建立全生命周期质量追溯机制，配合招标人开展质量抽检及不良行为处理。
