## 3. 本轮关闭的 P0 缺陷

### 缺陷

真实项目保存了明确带有“内部测试模拟值/非正式报价”的字段，但旧逻辑只判断字段非空，导致报价、保证金、授权代表、身份证号、签署日期、交货期和质保期被误判为正式客户确认，正式检查错误显示“允许正式版导出”。

### 修复

- `backend/services/bid_prefill.py`：新增正式确认值判定，拒绝内部测试、模拟值、非正式报价/保证金、仅供测试、待确认、需确认和待补充等值。
- `backend/services/formal_bid_check.py`：正式检查复用同一判定，模拟/待确认值形成阻断规则并展示原因。
- 新增单元测试，防止模拟值再次绕过正式导出门禁。
