## 三、真实生成发现的问题与修复

### 3.1 首次真实模型结果：未通过

首次对“投标人基本情况表”调用真实章节生成模型，耗时约 49.27 秒，模型实际返回约 3,440 字正文。虽然资料清单只包含 1 行结构化工商事实和 1 个营业执照证据包，但模型补写了未证实的生产许可、体系认证、财务和诉讼结论以及承诺性内容。

该结果按失败处理，没有以“模型成功返回”代替业务验收通过。

### 3.2 修复策略

- 为 `enterprise.basic_profile` 增加确定性事实渲染器，只输出已核验的 7 个工商字段；
- 为 `technical_characteristics.cpvc/mpp` 增加确定性参数表渲染器，只输出结构化检验结果、来源和适用边界；
- 高精度事实章节装配到合格 manifest 后，生产链路使用确定性渲染器写正文，不再让模型重写精确值；
- 论述型章节仍保留真实模型写作能力，但必须经过资料范围和越界审计；
- 增加占位项目名拒绝和招标编号提取测试。

确定性渲染器是正式生产代码路径，不是 mock；其目的就是保证工商事实、参数值和证据边界不被概率模型改写。
