## 兼容与失败策略

- 泰昌确定性证据包要求每个选中页携带资产 policy manifest；旧资产未设置 `quality_tier` 时，只有证据包已批准且资产满足 `allowed_for_bid=true + enterprise_fact + 泰昌 + full_page + 非 reference/exclude` 才可通过。
- 通用项目未启用泰昌证据包策略时不强制泰昌 metadata，继续沿用既有通用资产选择门禁。
- 图片插入数不一致、字段未刷新、固定表单审计失败、证据包漏页/整包跳过或 DOCX 命中内部路径/枚举/非正式题注，都会取消正式交付资格。
