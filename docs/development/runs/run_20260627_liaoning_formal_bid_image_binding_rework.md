# 2026-06-27 辽宁正式标书图片绑定与占位符清理回归

## 背景

用户反馈本地真实链路生成的辽宁项目标书存在正式交付不可接受的问题：正文仍有待补充/需人工复核/客户确认语句，章节正文与图片证据明显错配，单页图片缺少题注，标题存在斜体和字号异常。

## 根因

- 章节正文中历史生成的 Markdown 图片引用是合法 `/api/bidding/knowledge/assets/...` 链接，旧导出逻辑只删除不可解析图片，导致这些历史图片继续进入 DOCX。
- 新的资产选择器又会追加正式资产图片，形成“旧图片穿透 + 新图片追加”的双重配图，manifest 无法覆盖实际 Word 内图片。
- 商务标图片选择规则允许 `qualification_library` 宽泛证明材料，导致投标保证保险、泛认证章节误用绿色电力、体系认证等无关证书。
- 正文清理只覆盖 `待补充/需人工复核/客户确认后填写`，没有覆盖 `需人工核对/请确认/请提供/[ ]/XXX页/身份证号空线` 等正式场景草稿痕迹。
- DOCX 标题 run 继承了 Markdown 或模板中的斜体属性，未强制归一化。

## 本轮修复

- 导出时剥离章节正文中所有历史图片 Markdown，只允许正式资产选择器在导出阶段重新插入经 metadata 过滤的图片。
- 图片选择规则收紧：
  - 表格、索引、投标保证金/保险、保险购买凭证、银行基本账户等章节不自动插图。
  - 泛章节如 `认证证书` 不消耗具体证书图片。
  - 营业执照、三体系证书、业绩证明必须和资产标题/文本强匹配；无精确资产时不插图。
  - 商务标不再凭宽泛“证明材料/承诺附件”插图。
- 正文最终化清理覆盖草稿语气、checkbox、`XXX`、下划线空值、身份证号、签字日期等正式文件不可见痕迹，并写回当前项目章节正文。
- DOCX 标题和正文 run 明确关闭 italic/underline，避免斜体标题泄漏。
- 资产中文题注 fallback 固定为 `资料：<正式资产标题>`，不再生成空题注。
