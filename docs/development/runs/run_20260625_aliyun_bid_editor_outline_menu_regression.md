## 目标

验证目录模式中章节行“更多”菜单的真实可用性，并确认完成章节显示“篇幅偏长”是否存在客户误解风险。

## 实测结论

1. “更多”菜单存在，包含：自定义编写、新增子章节、修改标题、上移章节、下移章节、删除章节。
2. 在技术视图下对 `23.1.4 组织机构` 点击“新增子章节”，后端真实创建章节，章节总数 `185 -> 186`。
3. 新增章节没有继承父章节技术分册，API 显示 `volume_type=None`，导致技术视图不可见，切到“全部”后才显示。
4. 新增子章节后，原叶子章节 `23.1.4 组织机构` 变成“结构容器”，会静默改变正文生成语义。
5. “修改标题”弹窗可打开，标题 `新增章节 -> 测试临时章节-自动回归` 已通过 API 验证持久化。
6. 为验证移动能力，新增第二个临时兄弟章节。使用同一线上 `reorder` 接口调换顺序成功：`[自动回归, 新增章节] -> [新增章节, 自动回归]`。
7. 已删除两个临时章节并复核清理结果：章节总数恢复 `185`，临时章节 `0`，`组织机构` 下子节点 `0`。
