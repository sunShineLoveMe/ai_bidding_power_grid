## 缺陷优先级

### P0-1 正式导出门禁仍降级为草稿版

- 现象：技术标、商务标、整体标书导出均为 `exportMode=draft`。
- 门禁阻断项：
  - 正文残留占位符，导出任务 metadata 记录示例数量为 `125`。
  - 图片题注/manifest 中仍保留 `/api/bidding/knowledge/assets/` 内部资产路径，门禁判定为内部检索痕迹。
- 影响：明天演示时客户会看到“草稿版/阻断项”语义，正式交付可信度受损。
- 初步判断：人工确认页的 `ready_for_formal_export` 与导出门禁规则口径不一致；正文生成后缺少正式化清洗闭环。

### P0-2 正文过长和分页策略导致整体标书约 499 页

- 现象：整体 PDF 页脚显示 `第 2 页 共 499 页`。
- 目录中商务材料延伸到 `263` 页，技术材料延伸到 `484` 页。
- 影响：单个 CPVC/MPP 包演示文件体量严重失真，客户会认为系统不可控。
- 初步判断：章节写作目标字数过高、父章节独立分页、长证书/附件章节生成了大量解释性正文。

### P0-3 目录仍混入非本包物料 NHAP

- 现象：整体目录出现 `投标保证保险（电缆保护管 NHAP）`，正文审计也命中 `NHAP`。
- 影响：当前包为 CPVC/MPP，NHAP 属于明显串包/模板污染。
- 初步判断：参考大纲或物料拆分未按本包货物清单过滤。

### P0-4 正文残留“待补充/人工复核/占位符”语义

- DOCX XML 审计：
  - 技术标：`9` 处
  - 商务标：`13` 处
  - 整体标书：`22` 处
- 影响：正式投标文件不应出现系统提示、人工复核提示或占位符语义。
- 初步判断：部分章节写作策略允许占位符，但人工确认已经补齐字段，生成/导出层没有把可确认值回填或删除。

### P1-1 写作策略仍残留施工类提示

- 现象：生成任务 metadata 中技术章节 writing_plan 仍出现“施工部署、关键工序、质量安全环保”等供货类不适配措辞；DOCX 正文中仍命中 `施工组织` 1 处。
- 影响：供货投标场景下容易被客户认为行业理解不准确。
- 初步判断：大纲禁用词已生效，但写作策略模板仍未完全供货化。

### P1-2 封面字段口径仍需按新疆范本收敛

- 现象：整体封面字段显示 `招标人：国网辽宁省电力有限公司`，而底部另有 `投标人：河北泰昌电力器材科技有限公司`。
- 影响：视觉上比之前稳定，但与新疆范本/正式投标文件封面口径仍不完全一致。
- 建议：整体标书封面以投标文件、招标编号、包号/包名称、投标人、签章位、日期为核心，招标人可作为辅助字段或不展示。

### P1-3 目录和章节层级仍有重复/弱正式化问题

- 现象：
  - `投标人基本情况表` 在商务分册重复。
  - `专利证书` 在技术分册重复。
  - 第 3 页只有一级标题，正文从下一页开始，造成大量空白。
- 影响：正式观感不稳定，且显著增加页数。

### P1-4 解析阶段存在状态与质量提示不一致

- 现象：解析曾停留 `supabase_synced` 并触发自动恢复；最终产物为 `native_text`，但解释 metadata 中仍出现 `mineru` 口径；质量提示中“表格/图片结构已保留=false”。
- 影响：货物清单、参数表、评分表等结构化能力可能不稳定。

### P2-1 编辑器生成入口和页数预估体验问题

- 现象：
  - 正文模式缺少明显“一键生成全部正文”入口，需要切到目录模式或调用后台任务。
  - 0/102 生成时页面已显示约 `328` 页，容易制造焦虑。
- 影响：演示讲解成本高。

## 本次结论

上一次“大纲膨胀到 278 章”的问题本轮没有复现，当前大纲稳定在 `102` 节，说明供货类大纲门禁有效。但本轮暴露的问题不是单一脏数据，而是正式标书生成链路的系统性问题，主要集中在：

1. 物料/目录过滤仍未严格绑定本包货物清单。
2. 正文写作策略过长且仍允许系统占位提示。
3. 人工确认与正式导出门禁规则不一致。
4. DOCX 版式底座已基本可用，但内容正式化和分页控制未达演示标准。

建议优先按 P0-1 至 P0-4 收口，再做 P1 观感优化。
