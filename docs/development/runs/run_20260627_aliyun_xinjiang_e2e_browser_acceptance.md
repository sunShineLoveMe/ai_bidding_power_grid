## 缺陷 1：新疆项目资料域污染

严重级别：P0

### 现象

上传的招标文件为：

```text
国家电网有限公司2026年西北、西藏区域第一次联合采购10kV电力电缆、架空绝缘导线协议库存公开招标采购项目
招标编号：SL265A
包号：包1
目标物料：10kV 架空绝缘导线
```

但投标信息确认页出现旧辽宁/CPVC/MPP 内容：

- `辽宁 2025-03 2225AC 货物清单结构化行级记录`
- `电缆保护管CPVC、电缆保护管MPP`
- `CPVC电缆保护管检验报告`
- `MPP电缆保护管检验报告`
- `辽宁 2025-03 2225AC 技术参数表结构化记录`

继续生成技术章节后，污染进入正文。例如 22.1 招标要求正文生成：

- “针对本次国家电网有限公司2026年西北、西藏区域第一次联合采购（招标编号：SL265A，包1）的电缆保护管CPVC及MPP产品”
- “我公司提供的CPVC电缆保护管及MPP电缆保护管”
- “经我公司对照招标文件技术规范书、货物清单及技术参数表进行全面复核，我公司本次投标的所有产品（包括电缆保护管CPVC及MPP的所有规格型号）”

### 影响

这是正式投标文件不可接受的问题。系统识别到了新项目名称和 `SL265A`，但正文事实源仍混入旧辽宁电缆保护管资料，最终会生成错误投标产品、错误检验报告、错误技术参数和错误无偏差承诺。

### 初步判断

问题可能来自投标确认字段候选、技术参数候选或正文 RAG 写作事实包缺少当前招标文件/物料边界过滤。旧辽宁结构化参数和泰昌 CPVC/MPP 企业事实在新招标物料不匹配时不应自动进入当前项目字段和正文。

### 建议修复口径

- 预填字段、正文生成、技术参数候选必须绑定当前项目的 `tender_no`、物料类别、包件和 source_domain；
- 辽宁资料只能作为旧样本回归或 QA 参照，不得成为新疆项目事实输入；
- 泰昌 CPVC/MPP 检验报告只能在当前招标物料匹配电缆保护管时进入候选；
- 正式检查新增资料域一致性规则，至少识别“当前项目物料=架空绝缘导线，但正文命中 CPVC/MPP/电缆保护管/辽宁 2225AC”等强冲突。

## 缺陷 2：长项目名导致 DOCX 导出失败

严重级别：P0

### 现象

技术标草稿导出任务创建成功：

```text
POST /api/bidding/interpretations/580b8c82-42c2-4a51-a0d2-17b60afa22b9/download-docx
HTTP 201
task_id=d10fc57c-a0ca-472e-a432-d08a6130f10c
volumeType=technical
```

但任务最终失败：

```text
status=failed
progress=100
message=DOCX 导出失败，请查看错误信息。
error=[Errno 36] File name too long
```

失败路径包含完整超长项目名、投标人、技术标、图文和临时后缀：

```text
outputs/Guo_Jia_Dian_Wang_You_Xian_Gong_Si_2026Nian_Xi_Bei__Xi_Cang_Qu_Yu_Di_Yi_Ci_Lian_He_Cai_Gou_10kVDian_Li_Dian_Lan__Jia_Kong_Jue_Yuan_Dao_Xian_Xie_Yi_Ku_Cun_Gong_Kai_Zhao_Biao_Cai_Gou_Xiang_Mu/国家电网有限公司2026年西北、西藏区域第一次联合采购10kV电力电缆、架空绝缘导线协议库存公开招标采购项目投标文件-河北泰昌电力器材科技有限公司-技术标-图文.<uuid>.tmp.docx
```

### 影响

客户新提供的真实项目名称较长，技术标/商务标导出会直接失败，用户拿不到 DOCX 文件。

### 建议修复口径

- 输出目录名和文件名做安全截断，保留项目短名、招标编号、包号、投标人简称、分册类型即可；
- 目录名建议使用 `project_id` 或 `tender_no + package_no`，不要拼接完整项目名称拼音；
- 临时文件名必须控制在单段文件名长度限制内；
- `download_url` 对用户展示文件名可以保留较完整中文名，但物理路径必须短名化。

## 其他观察

- 正式检查能正确阻断报价、保证金、授权代表、身份证号、签署日期、质保期、投标有效期等缺失字段，并降级为“仅允许草稿版导出”。
- 技术标导出前会出现两层合理门禁：
  - 正文未完成门禁：技术标 54 个正文章节，已完成 1 个，待完成 53 个；
  - 条款响应门禁：技术标覆盖率 30%，30 项中 21 项待覆盖、7 项高风险待覆盖。
- 但是当前正式检查没有识别“项目物料与正文产品事实冲突”，因此无法防止资料域污染正文进入草稿导出。
- 编辑器页面没有在当前首屏/正文模式显示“一键编写全文”按钮，实际页面可见的是“生成本章正文”。代码存在批量生成能力，但本次真实用户路径中未直接暴露该入口，需要后续确认是否因页面布局、视口或状态导致。
