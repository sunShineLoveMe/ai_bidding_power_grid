# Run 20260620 - 标书工作台图文与质量指标口径收口

## 背景

用户在 AI 标书编写工作台核对目录模式和实时质量仪表盘时提出三点问题：

- 目录模式下“全篇图文并茂”不再需要作为用户开关，后续标书默认图文配合。
- 顶部“关联资料”容易被理解为手动关联企业知识库，但当前项目是单体项目，按钮没有实际动作，容易误导。
- 新增投标信息确认页后，实时质量仪表盘中的“响应率、未响应项、高风险未响应”等口径容易被误读为全量投标完成度。

## 处理结论

- 移除目录模式“全篇图文并茂”开关，前端内部固定 `withImages=true`，单章生成、批量生成和全文导出继续走图文配合。
- 移除正文模式和目录模式顶部“关联资料”空按钮。资料引用应由项目资料、企业事实库和检索链路自动承接，不在编写页让用户手动关联。
- 实时质量仪表盘保留，但口径调整为章节正文过程指标：
  - “条款覆盖率”：招标条款、评分项、风险项在章节正文中的覆盖追踪。
  - “待处理覆盖项”：未覆盖和待补强项合计。
  - “高风险待覆盖”：风险项、否决项、高优先级条款中仍缺正文覆盖证据的数量。
- 投标信息确认页字段不计入条款覆盖率；正式交付仍需单独的导出门禁检查前导页必填缺口、正文占位符、DOCX 格式和附件完整性。
