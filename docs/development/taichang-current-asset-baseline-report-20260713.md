## 8. 基线使用规则

后续解析《技术补充文件》《商务补充文件》时，必须使用以下稳定键比对：

1. 数据库图片资产：存储 bucket/path；缺失时使用源文件哈希 + 页码。
2. 知识文档：`doc_identity_key` 或源文件哈希。
3. 文档分块：文档 ID + chunk index + 正文哈希。
4. 产品参数：报告编号 + 产品族 +规格型号 + 参数名 + 原始行号。
5. 项目业绩：项目业务 ID + 证据类型 + 来源文件。
6. 原始资料：文件 SHA-256。

不得仅用文件名、标题相似度或“同为 MPP/CPVC”判断重复和适用性。
