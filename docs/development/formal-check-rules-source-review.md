更新日期：2026-06-24

适用规则集：`rules/power_grid/formal_bid_check_rules.v1.json`

## 核验结论

第一版 60 条规则采用“法规底线 + 标准招标文件组成 + 国网公开采购场景 + 本项目泰昌资料边界”四层来源。规则用于正式检查和风险提示，不作为自动法律结论，也不替代人工终审。

## 第一版规则口径

1. blocker 规则只用于阻断正式版导出，不阻断草稿版导出。
2. 金额、保证金、授权、签署日期、交货期、质保期、投标有效期等客户决策字段必须客户确认，系统不得编造。
3. 技术参数、保证值、偏差表等优先来自招标文件结构化数据和泰昌企业事实资料，模型不能猜测。
4. 泰昌企业事实、辽宁招标要求、河北豪乾参考稿必须隔离。
5. DOCX 成品检查必须在导出后复验，第一版接口在未传入导出任务时返回“需人工确认/导出后复验”。
