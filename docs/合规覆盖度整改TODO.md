# 合规覆盖度与下载前检查整改 TODO

## 背景

当前解读页显示“合规覆盖度 22%”，但用户已经生成并下载了标书。这个结果在技术口径上来自“招标条款与章节映射/正文片段的匹配率”，并不等同于最终 Word 标书是否合规。若继续使用“合规覆盖度”命名并放在不明显的 Tab 内，会让用户误判系统没有完成标书，或者误以为下载文件完全不可用。

## 目标

- 把指标命名从“合规覆盖度”调整为更准确的“条款响应覆盖率 / 要求映射覆盖率”。
- 在用户下载前明确提示未覆盖风险，而不是只在解读页静态展示。
- 后续支持点击未覆盖项定位章节、一键生成补强内容，并在正文生成后自动刷新检查结果。

## P0：指标口径和下载前风险提示

- [x] 解读页顶部指标卡展示“条款响应率”，让用户一进入页面就能看到。
- [x] 指标卡图标支持鼠标悬浮说明，解释要求条款、风险条款、评分项、条款响应率和章节大纲的业务含义。
- [x] 将 Tab 名称从“合规覆盖”改为“条款响应”。
- [x] 在指标说明中明确：该值是招标条款到当前章节/正文的响应追踪，不等同于最终 Word 合规结论。
- [x] 下载完整标书或分册前拉取最新条款响应报告。
- [x] 若存在未覆盖或高风险未覆盖项，下载前弹窗提示风险数量，并允许用户选择继续下载或返回补强。
- [x] 同步 README、`task_plan.md` 和 `notes.md`。

- [x] 展示正文字数估算：按当前章节正文统计总字数。
- [x] 展示条款响应率：复用 `/compliance-check` 最新结果。
